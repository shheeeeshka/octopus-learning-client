# Octopus - SQL Learning App

## Description

SQL Learning App is an interactive application built with React that helps users learn the fundamentals of SQL. The app includes theoretical blocks, practical exercises, and quizzes to test knowledge.

## Features

- **Theoretical Blocks**: Users can study various SQL topics, including:
  - SQL Basics
  - Data Retrieval Operators
  - Data Manipulation Operators
  - Working with Tables and Databases

- **Practical Exercises**: Each topic is accompanied by practical exercises to reinforce learning.

- **Quizzes**: Users can take quizzes to test their knowledge and receive feedback on their results.
